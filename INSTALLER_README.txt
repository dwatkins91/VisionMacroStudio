VISION MACRO STUDIO 1.0.0
=========================

Vision Macro Studio is a local Windows application for capturing and labeling
screen objects, training YOLO detection models, and building visual macros.

IMPORTANT UNSIGNED-RELEASE NOTICE
---------------------------------

This installer and the enclosed application are not Authenticode signed.
Windows may display "Unknown publisher," Microsoft Defender SmartScreen may
show a warning, and Smart App Control or an organizational application-control
policy may block installation or a native dependency. Do not disable Windows
security protections simply to install the program.

Only continue if you intentionally downloaded this installer from the official
Vision Macro Studio GitHub release:

https://github.com/dwatkins91/VisionMacroStudio/releases/tag/v1.0.0

Compare the installer against SHA256SUMS.txt on that release before running it.

The program sends real mouse and keyboard input when a live macro is run. Start
with Safe Step Preview, set a short run limit, and keep F12 available as the
default emergency stop. Use automation only where it is authorized.

Captures, datasets, trained models, macros, logs, and settings remain local to
the project directory selected by the user. Vision Macro Studio has no
telemetry, advertising, automatic upload, or silent update check.
