# Support and bug reports

Vision Macro Studio is an experimental community project. The best support
path is a GitHub issue with a narrow, reproducible example.

Before reporting a problem:

1. Confirm the app version in **Help → About and License**.
2. Run **Help → Check My Computer**.
3. Use **Validate Macro** and **Safe Step Preview** for macro problems.
4. Reproduce the issue once with the smallest practical project or sample.
5. Open **Logs → Create Diagnostic Package** and review every included file.
6. Search existing GitHub issues before opening a new one.

Never attach private screenshots, credentials, account information, proprietary
models, or an unreviewed project export. A diagnostic package deliberately
excludes those files, but its class names and macro structure may still reveal
what you were automating.

Issues: <https://github.com/dwatkins91/VisionMacroStudio/issues>

Security vulnerabilities should be reported privately as described in
[`SECURITY.md`](SECURITY.md).
